# 다크 스파이어 (The Dark Spire) 한국어 패치 v1.0

**2026-11-09 · Nintendo DS 북미판 YEAE 전용**

게임 대사·이벤트·전투 및 시스템 텍스트, 메뉴와 관련 이미지에 한국어를 적용했습니다. 모던·감마·클래식 화면 모드를 지원하며, 한글 표시 및 조사 처리·이름 입력과 저장 관련 UI 보정이 포함됩니다.

최종 실게임 QA에서 확인한 파티 상태 메뉴 `지도/물품/뒤로` 선택 하이라이트·오표시 그래픽 문제와 빈 기술·주문 안내 문구 개선을 반영했습니다.

## 적용

ZIP 압축을 푼 뒤 Windows 64비트에서는 정품 북미판 원본 `.nds`를 `PATCH.bat`에 끌어다 놓습니다. 다른 운영체제에서는 동봉된 `DarkSpire_USA_to_Korean_v1.0.bps`를 BPS 지원 패처로 적용합니다. **한국어 패치가 이미 적용된 ROM이나 다른 국가·개정판에는 적용하지 마세요.**

| 대상 | SHA-256 | CRC32 |
|---|---|---|
| USA 원본 (32MiB) | `3152b94c8f7e5a4b0d5582db74ace7e120afe1f6a95ee83b22c517ff1c4f9092` | `F07DEF81` |
| 최종 한국어 ROM (32MiB) | `9e90e78963697ccbb3ad3827e33369c931ad6a8cf73d1da256565e4502235753` | `7AFE3CB7` |

배포 ZIP SHA-256: `e7d03338fcfdc3697bf87cd5f368eb8752dff14355349b8e1e6404c665b1e91c`

실게임 QA는 사용자 지정 검수 범위에서 PASS이며, 전체 게임 완주·모든 실물 기기 환경의 전수 검증은 아닙니다. Windows용 패처는 교차 빌드되었고 Linux의 동일 Go 소스 패처 적용이 검증됐으나, Windows 실환경 실행 증거는 없습니다.

비공식 팬 제작물입니다. 게임 ROM·BIOS·세이브는 제공하지 않으며 정당하게 보유한 북미판 원본에 적용하세요. 원작의 저작권과 상표권은 각 권리자에게 있습니다.
