## 다운로드와 적용

배포가 승인되면 각 프로젝트의 GitHub Releases 항목에 ZIP과 사용법을 게시합니다. 태그는 `프로젝트--v버전` 형식입니다. 아직 다운로드가 없는 항목은 개발 또는 배포 검토 중입니다.

본인이 정당하게 보유한 지원 판본에만 패치를 적용하세요. 정확한 입력 SHA-256과 지원 판본은 각 릴리스 사용법을 따릅니다.

## 포함 범위

패치·실행용 앱·사용법·변경 이력만 배포합니다. 원본 게임, 추출 리소스, 개발 인계 기록, 개인 그림·등록 데이터·비밀정보는 포함하지 않습니다.

## 저작권과 제보

게임과 상표의 권리는 각 권리자에게 있습니다. 패치 코드·앱과 제3자 도구의 라이선스는 릴리스별 안내를 따릅니다. [저작권 안내](COPYRIGHT.md)를 확인하고 문제 제보는 이 저장소의 Issues를 이용해주세요.
