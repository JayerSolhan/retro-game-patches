## 사용 안내

각 릴리스의 지원 판본과 입력 SHA-256을 확인하고 본인이 보유한 원본에 적용하세요. 게임 ROM·디스크 이미지·BIOS·추출 리소스·세이브는 제공하지 않습니다. 정식 배포본의 검사 범위와 실기 미검증 여부는 개별 사용법을 따릅니다.

개발 자료와 인계 기록은 공개하지 않습니다. 포함 도구와 글꼴의 라이선스는 각 배포물에 동봉된 안내를 확인하세요. [저작권 안내](COPYRIGHT.md) · [배포 이력](CHANGELOG.md)
