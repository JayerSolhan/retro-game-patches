## 사용 안내

각 릴리스의 지원 판본과 입력 SHA-256을 확인하고 본인이 보유한 원본에 적용하세요. 게임 ROM·디스크 이미지·BIOS·세이브는 제공하지 않습니다. 검증 범위와 실기 미검증 여부는 각 사용법을 따릅니다.
