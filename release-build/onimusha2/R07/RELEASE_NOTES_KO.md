- 이전 모던 이동, 카메라 컷 방향 유지, 십자키·버튼 원작 기능은 보존합니다.
- 디버그/QA 캐릭터 선택기는 포함하지 않습니다.
- 원본 ISO, DVD CHD, 단일 트랙 `CHT2/MODE1` CD CHD에 대응하며, 추출 후 안전 검증과 재압축 이미지 전체 데이터 검사를 수행합니다.

### 설치 방법
압축을 풀면 **치트**(`CHEATS/106A1E75.pnach`)와 **영구패처**(`PATCH_ONIMUSHA2.bat`)를 함께 제공합니다. 둘 중 **하나만** 사용하세요.

- 치트: PCSX2의 cheats 폴더에 `106A1E75.pnach` 복사 후 활성화
- 영구패처: 미패치 한국판 원본 ISO/CHD를 `PATCH_ONIMUSHA2.bat`에 드래그. 원본은 보존되며 `_modern_control_R07`이 붙은 새 이미지 생성. 새 이미지 실행 시 동일 모던 치트 비활성화
- Windows 10/11 64비트; Python·Go 별도 설치 불필요, CHD 변환 도구 동봉
